Sistema de Exaustão e Alarme

Simulação das entradas A, B e C e da saída S, conforme as regras de segurança da atividade.

Entrada A — Sensor de Fumaça

0 = Ambiente normal
1 = Fumaça detectada

Valor atual: 0

Entrada B — Sensor de Temperatura

0 = Temperatura normal
1 = Temperatura acima do limite

Valor atual: 0

Entrada C — Chave de Manutenção

0 = Operação automática
1 = Técnico realizando manutenção

Valor atual: 0

Saída S

Sistema desligado — S = 0

Lógica utilizada:

S = A || (B && !C)
